## Practice method
1. Answer clarification questions aloud and state assumptions.
2. Sketch entities and relationships before opening the diagrams.
3. Walk the sequence and identify failure/concurrency boundaries.
4. Implement a slice and test edge cases.
5. Explain trade-offs without claiming guarantees the code does not provide.
