# Visual assets

This folder contains companion artwork for the LLD interview playbook.

- `lld-interview-workflow.png` — overview of the problem-solving sequence.

Editable Mermaid diagram sources are stored in `../diagrams/` and embedded in the playbook. This keeps the diagrams reviewable in Git and renderable by Mermaid-compatible Markdown viewers.


Pattern-specific walkthrough SVGs are named `<pattern>-visual.svg` and are embedded in the matching guide under **Visual walkthrough**. Each visual is a conceptual flow; the adjacent explanation calls out the key design invariant or failure boundary.
